# RnxFotoo

Цифровая фоторамка для Windows на C# и WinUI 3. Подключите локальные папки, интернет-подборки или оба источника и запустите слайд-шоу в окне или на весь экран.

## Запуск

Готовая сборка для Windows x64 запускается через `artifacts\win-x64\RnxFotoo.exe`. Храните EXE вместе с остальными файлами сборки.

Для запуска из исходников на Windows установите SDK .NET 10 и выполните в папке проекта:

```powershell
dotnet run
```

Для публикации автономной сборки x64 с .NET и Windows App SDK:

```powershell
dotnet publish -c Release -r win-x64 --self-contained true -o artifacts/win-x64
```

## Источники

1. **Локальные папки.** Нажмите **Добавить папку** или `Ctrl+O`. При необходимости включите **Включать подпапки**. После изменения файлов на диске нажмите кнопку обновления рядом с заголовком **Локальные папки**. Приложение читает фотографии на месте.
2. **Интернет.** Нажмите **Добавить интернет-источник**. Выберите Яндекс.Картинки, Google Images или Pinterest и введите запрос. Можно также вставить адрес галереи, доски или изображения с любого сайта. Откройте страницу, прокрутите её для загрузки дополнительных снимков и нажмите **Добавить в фоторамку**. За один раз можно сохранить до 36 снимков из загруженной части страницы. Кнопка обновления рядом с подборкой открывает её страницу, где можно заново собрать снимки.

Загруженные подборки доступны без сети. Удаление источника из списка исключает его снимки из показа и удаляет локальную копию интернет-подборки. Для открытия страниц используется Microsoft Edge WebView2 Runtime. Некоторые сайты могут ограничивать доступ к результатам поиска и загрузку снимков.

## Управление

- **На весь экран** или `F11` открывает полноэкранный режим. `Esc` возвращает в окно. Движение указателя показывает панель управления в полноэкранном режиме.
- `←` и `→` листают кадры, `Пробел` ставит показ на паузу или продолжает его. В оконном режиме сначала щёлкните по фотографии для фокусировки.
- В настройках можно выбрать интервал от 3 до 60 секунд, вписать фото целиком или заполнить кадр, включить перемешивание, плавный переход и часы. Когда фоторамка открыта на весь экран, Windows держит дисплей включённым.

Поддерживаются JPEG, PNG, BMP, GIF, TIFF, WebP и HEIF/HEIC при наличии соответствующего декодера Windows. Для анимированных и многостраничных файлов показывается первый кадр. Нечитаемые снимки пропускаются.

Источники и параметры сохраняются в `%LOCALAPPDATA%\RnxFotoo\settings.json`, сохранённые интернет-снимки — в подпапке `online`. Изображение озера на стартовом экране используется для предпросмотра.
